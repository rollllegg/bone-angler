# 炼药改版说明

本分支实现《炼药新设计》2026年11月26日版本，并按本次讨论追加静鳍鳅、自动材料入库以及体型只由鱼钩决定。设计表保存在 `game/data/alchemy/design.json`，运行时使用 `alchemy_rules.gd`。飞书计划案中的原液直饮、双原液复方、旧鱼饵与旧收费规则，在本次改版范围内由用户批准的新设计替代。

## 追加规则

- 保留静鳍鳅：浅水权重5，深水0；回声鳊浅水0，深水15。两者均为一级意志抑制材料，共用息执原液。保留12种鱼、11种材料与11种成品，两个水域基础总权重均为100。
- 捕获成功后直接获得原液。普通鱼小／中／大产2／3／4份，巨刺固定3份。取消鱼篓和手动提炼页，鱼图鉴仍保存鱼种、数量与最大体长。
- 小型凝魂幽灯鱼直接额外给予一份浓缩的灵魂。强化成品每剂一次，单项±1；原液不能强化或直饮。
- 鱼体型只由鱼钩决定，不设置体型饵。鱼饵为基础、智慧、情感、意志和异刺五种，单价2／4／4／4／8，属性饵只影响鱼种，不改变体型。
- 混炼和跨等级混炼不在本阶段开放；旧78种复方和中和规则退出正常制作流程。

## 接待与补给

首日固定情感与意志下限7，跳过教程也相同。每个新存档发放冥河原液3份、幽灯原液6份，教学中型冥河鲫正常增加冥河原液3份。前两天普通来客只在一个方向上与要求相差1，其他属性留出升阶药副作用的空间，本级和升阶产物均可达标。

每日仍为六个席位。第1天末位孙悟空，第2天末位俄耳普斯，第5天末位阿努比斯；第三天琴手回访条件保留，其情感或意志失衡按当天受检属性生成，避免出现无需用药的回访。普通人物从30个固定缺陷模板生成，不在同一天重复，跨日候选不足时复用兼容人物。订单按开班时的区间和库存生成并锁定，不会在端药后改写。三级病例按库存洞识药数量限制投放，未持有时不会强制出现；两剂病例第四天起每天最多一个。

第一次出现属性上限时，一次性核对本日普通来客：先通过一剂一人的库存匹配，再分配已有原液，缺额补足至可服务五人，稀缺方向优先。若有第六名普通来客，为其方向保留一份尾料；五人或以下不另造一个第六人缺口。两种补给均有存档标记，不重复领取。

报价采用未强化标准药表，先核验是否能一剂完成，再取可用最低等级：25／40／60。原生两剂病例报价80，正常实收40。初次服务和原有船工委托各加基础报价10%向下取整，合计后再按累计剂数减半。玩家实际选高级药、强化或额外补药不会提高已锁定报价。剧情角色继续使用独立的评分和报酬，其反应按新版实际药效重新计算。

文档中的六名普通来客材料满足率、两日268金币和购装备后余58金币属于原模型，不作为本分支实机保证。当前剧情占位、跨日人物复用、真实捕获成功率及玩家误配都会影响结果。测试核验药表、概率、生成可解性与实际资源扣除，不将材料模型数字当作实机测量结果。

## 存档与图鉴

规则版本为20。新档保存原液尾料、成品实际药效、强化状态、固定日程与初值、锁定报价、两种补给标记、异刺工艺以及炼药随机序列。读档后从原随机位置继续，不重新抽取未来结果。

旧鱼篓一次性按新产量折为原液，静鳍尾料合入息执原液；已经结算的指骨不重复发放。旧同名药采用新版标准药效，其余旧成品按三项药效绝对差总和最近的标准药转换，平局按标准药表顺序。旧强化状态清除，保留药剂数量与物品编号。旧正负属性饵合并为对应新属性饵，遗骨饵折成基础饵，历史体型饵等量折成基础饵。旧档不补发新手或首次上限补给。历史鱼种和捕获记录保留，旧复方发现记录退役，现有成品可补建对应新药图鉴。

图鉴分鱼类、原液、成品三页。鱼类页展示捕获资料、药材等级和原液入口；原液页展示来源鱼与逐个发现的产物概率；成品页展示固定标准药效、唯一主属性分类和各个来源入口。端药预览显示实际药效、最终属性与预计报酬。
