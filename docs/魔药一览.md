## 强化

- 提炼小型凝魂幽灯鱼额外获得 1 份浓缩。
- 炼药台可消耗 1 份浓缩，给任意一份原液或复方单属性 +1 或 -1，可重复叠加。
- 原液被强化后会变成一份独立药剂；复方被强化后直接改写原药剂。
- 因此 78 种只是底方，实际药效会因强化而偏移。
