# Bone Angler · 骨灰级钓手

## 整体试玩 Demo

双击 `启动/运行游戏.cmd`，或运行已导出的 `game/build/windows/BoneFishing.exe`。封面选中「开始游戏」后，可以在冥河钓鱼、到炼药台用原液制药、给灵魂端药，再手动放行。试玩共五天，每天 6 位来客，共 30 位。来客间隔为 20～25 秒。

| 界面 | 键盘操作 |
| --- | --- |
| 封面 | W / S 选择，空格确认，C 返回。「继续游戏」可选择存档 |
| 地点切换 | Q 向左、E 向右，在河岸、接待、炼药、市场之间循环。也可点击顶部页签 |
| 河岸 | 空格抛竿，X 中断收竿。按箭头对应的 WASD 或方向键逆向拉鱼。点拉到边界点按，绷线持续按住，猛冲金环亮起时松开 |
| 钓组 | Shift 开始换件，时间照常流逝。W / S 选槽位，空格打开列表。鱼饵用 WASD 选择，其他部件用 W / S，空格确认。C 逐级返回 |
| 接待 | A / D 选等候的来客，W / S 选药剂并预览，空格喂药，Shift 放行 |
| 炼药 | WASD 选择原液或成品，空格／F 消耗三份同种原液炼药，Shift 切换纯炼与强化。强化时 X 换属性、V 切换增减 |
| 市场 | W / S 选类别，空格进入，再用 W / S 选商品、空格购买或维修。A / D 调整鱼饵数量，C 返回上一级 |
| 暂停 | Esc 或左上角圆形图标可暂停和继续。A / D 或 W / S 选择暂停菜单选项，空格确认，C 返回上一级。切出游戏时默认自动暂停 |

游戏提供五个手动存档位。暂停后可直接存入空位，选择已有进度的位置时需确认覆盖。封面的「继续游戏」也能读取存档。在保存或读取窗口点击存档右侧的「删除」，也可选中存档后按 Delete，确认后删除该槽。旧版单一存档可在第一个存档位读取。绷线进度随存档保存，读档后重新按住对应方向键即可继续。

开局配给 40 枚渡魂币、10 个素指骨饵、浅水短杆、小号钩和基础握柄，以及一次性的冥河原液 3 份、幽灯原液 6 份。首日固定检查情感、意志至少 7，无论是否开启教程。教程捕获一尾中型冥河鲫，正常获得 3 份冥河原液。

两种水域有 11 种普通鱼，以及深水异刺拟饵触发的巨刺灰鳞鱼。静鳍鳅在浅水权重为 5，回声鳊只在深水权重为 15；两者共用息执原液。成功捕获后，小／中／大普通鱼直接获得 2／3／4 份原液，巨刺固定 3 份，不再进入鱼篓或手动提炼。鱼图鉴仍记录捕获数量和最大体长，小型凝魂幽灯鱼仍额外提供浓缩的灵魂。

原液是材料，不能端给来客。炼药台消耗三份同种原液，必得一剂成品：一级材料 70% 本级、30% 升二级；二级材料 80% 本级、20% 升三级；巨刺材料必得洞识药。共有 11 种固定成品药，本阶段不开放混炼与旧复方。每剂成品仍可用一份浓缩的灵魂调整一项 ±1，限一次。详细数值见 [魔药一览](docs/魔药一览.md)。

市场出售基础饵、三种属性饵和异刺拟饵，共五种，单价依次为 2、4／4／4、8。属性饵提高对应属性正反两类鱼的相对权重 ×3。小、中、大体型概率只由鱼钩决定，鱼饵不影响体型。异刺工艺需要拥有长杆后支付一次性 80 枚解锁。常规上钩全部进入鱼类分支，取消遗骨饵与直接遗骨事件。基础握柄在耐久归零后可花 6 枚临修至 5 点，或花 10 枚整修至 10 点。长杆仍为 160 枚，中号钩为 50 枚。

普通来客保留固定缺陷，按当天放行区间生成初值，三项均在 1～10。前两日单项教学病例兼容对应原液的本级和升阶产物。第三日起引入复合缺陷，第四、五天可少量出现两剂病例；三级推荐病例只有在已有洞识药时投放。当天普通来客不重复，跨日候选不足时复用兼容人物。剧情角色仍占每天六个席位中的原定位置。

普通来客入场按未强化标准药表的最少剂数和最低药品等级锁定报价：一级 25、二级 40、三级 60，原生两剂病例 80。第一剂全额，之后每多一剂将基础价和适用奖金的合计减半并向下取整；首次接待和船工委托沿用各 10% 加成。首次引入上限时，按当天普通来客和现有库存补足至可服务五人；若有第六名普通来客，保留该方向一份尾料。剧情报酬独立结算。

图鉴分鱼类、原液、成品三页。首次炼出某种成品后，解锁该原液到该成品的概率；成品图鉴列出标准药效和材料入口。新存档保存补给领取状态、异刺工艺、材料尾料、预生成来客和炼药随机序列。旧鱼篓读档时一次性转换为材料，旧药转换为新版标准药，旧鱼饵按用途迁移。改版细则与旧档处理见 [炼药改版说明](docs/炼药改版说明.md)。

来客达到当天要求后，按 Shift 放行，灵魂会沿石路走入冥府大门。前一位离场时即可接待下一位。切换地点会保留抛竿、拉鱼与送客动画进度。

浮漂入水后等 3～8 秒上钩，通常为 5 秒。上钩前收竿会保留鱼饵和耐久。候鱼时切换地点，候鱼计时继续。在其他页面时有鱼上钩，屏幕左侧会弹出感叹号气泡，河岸页签也会亮起红色感叹号。此时按 Q 或点击河岸页签，在 3 秒内直接返回可开始拉鱼或真名捕获。超时后鱼会脱钩，上钩时消耗的鱼饵和耐久照常扣除。暂停或离开河岸后，重新按住对应方向键即可继续绷线。

背景和动态鱼线按 405×243 像素网格绘制，界面独立叠加。河景、店铺、鱼竿、封面与灵魂帧均已通过 PerfectPixel，仓库包含 `game/assets/art/demo/` 下的运行素材与 `sources.json` 来源记录。详细制作记录 `game/assets/SOURCES.md` 和原始生成图 `game/art/source` 保留在本地，不影响克隆后运行 Demo。

新入口为 `game/scenes/demo/demo.tscn`。旧的组装、字母钓鱼和独立玩法练习仍保留在 `game/scenes/main.tscn`，可在编辑器中单独运行。

## 开发环境

- Windows 64 位。
- Godot **4.7.2 Standard**，使用 GDScript 和 Compatibility 兼容渲染模式。
- Godot **4.7.2** 导出模板，用于导出 Windows x64 和 Web 版本。
- Git，用于版本管理。
- Python **3.10**，用于本地预览 Web 版本。
- 可选：VS Code 和 Godot Tools **2.7.1** 扩展；也可以使用 Godot 内置脚本编辑器。

工具版本、下载地址和校验值统一记录在 `game/tools/toolchain.json`。

## 准备环境

在仓库根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\game\tools\Install-Environment.ps1 -SkipCreativeTools
```

脚本会准备 Godot、对应导出模板和编辑器扩展，便携工具保存在 `game/.tools/`。

如果已经安装 Godot 4.7.2，可直接导入 `game/project.godot`，按 F5 运行。

## 启动与检查

- `启动/启动编辑器.cmd`：打开 Godot 工程。
- `启动/运行游戏.cmd`：运行游戏。
- `启动/剧情测试.cmd`：全部特殊 NPC 集中在同一队列，可直接切换测试；按 `N` 或点击队列右上角重置，并附带测试药剂。

## 像素图后处理

本项目以后新生成或重新生成的像素图，交付前统一经过 [PerfectPixel](https://github.com/theamusing/perfectPixel) 处理并检查。

- 将一张或多张图片拖到 `启动/像素图后处理.cmd` 上处理。
- 原图保留，结果另存为同目录下的 `原文件名.perfect.png`，并附带 `.perfect.json` 处理记录。已有结果不会被覆盖。
- 默认保留采样得到的透明通道，关闭自动补行、删行的正方形修正；仍需检查实际输出尺寸、细线和动画帧的一致性。
- 自动识别失败时，可指定 `--grid 宽 高` 重试；原图与处理稿保存在 `game/art/source`，确认后的正式素材放入 `game/assets/art`，并记录在 `game/assets/SOURCES.md`。

首次安装或在另一台电脑上准备工具：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\game\tools\Install-PerfectPixel.ps1
```

指定网格或输出位置：

```powershell
.\game\.tools\perfect-pixel\venv\Scripts\python.exe .\game\tools\perfect_pixel.py "原图.png" --grid 64 64 --output "处理稿.png"
```

源码与处理环境位于 `game/.tools/perfect-pixel/`，上游提交与源码压缩包校验值固定在 `game/tools/toolchain.json`；安装脚本复用已有兼容依赖，缺失的依赖仅安装到项目内的 Python 环境。

## 剧情系统

孙悟空是第 1 天第 6 位、也是当天最后一位来客，俄耳普斯是第 2 天第 6 位；第 1 天前 5 位均为普通亡灵，第 5 天最后一位是进行“称心”的阿努比斯。特殊来客沿用接待窗口的头顶对话框、空格给药和 Shift 放行。选中特殊来客时，左上角三项属性显示问号；立绘上的“可疑部位”默认可点击，无需先推进开场。按 F 或点击对话框继续，对话框右下角显示 F 提示；对话正文不加姓名前缀。悟空可调查脸和棍子，俄耳普斯只调查里拉琴；查看道具时，独立道具会展示在 NPC 身前，已调查热点保留为灰色。右下角可点「真名解放」，输入 `SUNWUKONG`、`ORPHEUS` 或 `ANUBIS` 成功后，悟空显出本相、俄耳普斯露出真容；阿努比斯没有战斗，只在最后用天平称量你放回的渡魂币。称心结束后会隐藏接待界面，进入只保留阿努比斯、天平和结局文字的结局卡。

双击 `启动/剧情测试.cmd` 可按天测试全部已实现的特殊 NPC：第 1 天接待悟空，送客后显示原有的每日结算弹窗；关闭结算后才生成第 2 天的俄耳普斯，并继承悟空的实际结局。俄耳普斯结算后，只有悲剧结局才会在第 3 天生成殉情的琴手回访；团聚结局直接跳过回访。没有剧情来客的日期自动跳过，最后进入第 5 天阿努比斯终审与原有结局卡。测试场跳过普通来客，预备 200 枚渡魂币和三瓶测试药剂，免除普通属性检查，关闭存档。按 `N` 或点击队列右上角可从第 1 天重置剧情状态、渡魂币和药剂；结算弹窗与结局卡上也可按 `N` 重测。正常试玩使用 `启动/运行游戏.cmd`。

编译、模拟和测试命令见 `docs/剧情系统使用说明.md`，结构设计见 `docs/剧情系统设计.md`，动作旁白的演出与特效见 `docs/剧情演出与特效方案.md`。演出 cue 在 `narrative/derived/cues/`，当前包含屏幕震动/闪色/缩放、9 个道具、9 张基础特殊立绘和 4 张无道具展示变体；素材来源与后处理见 `game/assets/SOURCES.md`。
